Subway Movers

A tiny always-on-top window watches you through the webcam and turns your steps, jumps, and ducks into arrow-key taps, straight into the web game or BlueStacks.

How it plays

←

Lean left

Step or lean left to switch a lane. Moves are relative to wherever you're standing.

→

Lean right

Same idea, mirrored. One sidestep never drifts you out of frame.

↑

Jump

Jump up in place to clear a hurdle. Locked out right after so it never fires a duck too.

↓

Duck

Crouch to roll under a barrier. Pose detection runs fully on-device via MediaPipe.

Two minutes, one webcam

Get it running

# clone and install git clone https://github.com/YOUR_USERNAME/subway-movers.git cd subway-movers npm install npm run dev
  • 01 A frameless window drops into the top-left corner and floats above everything, even fullscreen games.
  • 02 Pick a target, Web or BlueStacks, and hit Play. Grant camera access when asked.
  • 03 Step back until your whole body is in frame during the countdown.
  • 04 Stand neutral through the short calibration, then move to play.
